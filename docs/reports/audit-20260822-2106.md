### 维度 4 — Bug 模式

- **B-01 (Minor)** guard 关机/重启正则误伤字符串内容与子串（实测 3/13 误伤）：
  - `global/plugins/guard/index.mjs:24` `\b(?:shutdown|reboot|halt|poweroff)\b` 匹配命令文本任意位置的词：
    - ❌ `npm run shutdown-handler-test`（脚本名含 shutdown）被阻断
    - ❌ `Write-Host "server will halt soon"`（字符串含 halt）被阻断
    - ❌ `echo "please do not reboot the server"`（字符串含 reboot）被阻断
  - 影响: 合法命令被阻断 → 需 `OPENCODE_DISABLE_GUARD=1` 绕过，破坏工作流顺滑度；且违反 DoD"合法操作不误伤"。
  - 修复: 收紧为命令首 token 语义（如 `(?:^|\s)(?:shutdown|reboot|halt|poweroff)\s` 且排除引号内），并将矩阵实测落盘（见 P-02）。

- **B-02 (Info)** 逃生阀一致：`SKIP_VIBE_GATE=1`（vibe-gate/quality-gate）与 `OPENCODE_DISABLE_GUARD=1`（guard）均要求显式设置，机制对称。✅

- **B-03 (Info)** `guard/index.mjs:21` git push 正则 `\bgit\s+push\b[^;\n]*--force(?!-)` 正确放行 `--force-with-lease`（实测通过），`-f` 短旗标也覆盖（实测 `git push -f origin main` 拦截）。✅
