# Security Baseline — [项目名称]

> 安全基线：与架构选型同生命周期（vibe-plan 阶段3 生成），实现与评审的对照基准。
> 反臃肿原则：小项目允许逐项标注"不适用(理由)"，但每项必须有答案（G05.5 校验存在性，不校验内容质量）。
> 来源：02-ARCHITECTURE.md §4 服务端边界 + §9 安全相关选型展开。
